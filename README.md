# 🌍 Popular Destinations

## 📖 Project Description
This project is a simple travel-themed webpage built with **HTML, CSS, and JavaScript**.  
It showcases famous destinations around the world, each with:
- A **title** (e.g., Paris, Tokyo, Bali)  
- A **description** (short text about why it’s popular)  
- A **button** (interactive element that shows extra info using JavaScript)  

The design uses **CSS** for styling and **JavaScript** for interactivity.

---

## 🧩 Features
- Clean and responsive layout with destination cards  
- Hover effects and shadows for better UI  
- Interactive buttons that display fun facts about each destination  
- Easy to expand with more destinations  

---

## 🛠️ Tech Stack
- **HTML** → Structure of the webpage  
- **CSS** → Styling (colors, fonts, hover effects, layout)  
- **JavaScript** → Interactivity (alerts or hidden text toggle)  

---

## 🚀 How to Run
1. Clone or download the project files.  
2. Open `index.html` in your browser.  
3. Explore the destinations and click **More Info** buttons for details.  

---

## 📸 Example Destinations
- **Paris, France** → Known as the City of Light, famous for art, fashion, and cuisine.  
- **Tokyo, Japan** → A bustling metropolis blending tradition and technology.  
- **Bali, Indonesia** → A tropical paradise with beaches and cultural traditions.
